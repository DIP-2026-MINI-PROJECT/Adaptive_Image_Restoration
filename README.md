# Adaptive Image Restoration
   DIP mini project: detects periodic, Gaussian, speckle and salt-and-pepper
   noise automatically and removes each with an adaptive filter.

   ## Contributors
   Ananya (PES1UG24EC025), Aishwarya Raj K (PES1UG24EC021), Ankitha R (PES1UG25EC802)
   Guide: Spoorthi

   ## Requirements
   MATLAB with the Image Processing Toolbox

   ## How to run
   git clone https://github.com/<username>/adaptive-image-restoration.git
   Open the folder in MATLAB and run main.m
   Outputs are saved to Results/A_Concepts and Results/B_TestCases
